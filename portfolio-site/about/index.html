Simple by design.

The current iMarked experience is intentionally built as a frontend-only prototype. Profiles added through the interface are stored using your browser’s localStorage.

  • No account, server, or database is required.
  • Profiles remain on the current browser and device.
  • Data is not automatically shared with other visitors.
  • Clearing browser storage can remove locally saved profiles.

This makes the prototype fast, lightweight, and easy to experiment with.
